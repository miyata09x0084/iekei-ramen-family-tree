# ADR 0004: 企画・要件定義書に沿って「ツギイエ」へ全面改修する

- 日付: 2026-10-09
- 状態: 採択（CLAUDE.md の「数を追わない」「味の評価とおすすめは扱わない」を置き換える。ADR 0001 の前提「定期作業・返信・締め切りを生まない」は維持する）

2026-10-08 の企画・要件定義書と基本設計書（外部設計）に沿い、系図を眺めるサイトから「訪問記録をもとに次の一杯を理由つきで提案する」サービスへ全面改修する。提案・訪問記録・味メモ・Google ログインを足すため、「数を追わない」「おすすめを扱わない」はそのままでは成り立たず、「数は測るが約束しない」「他人の評価は扱わない」に置き換える。一方、成功指標の達成や要件定義書の「誤りの報告に 7 日以内で対応」を約束すると返信義務と締め切りが生まれるため、ADR 0001 の前提は維持し、7 日以内は採らない。

同じリポジトリで段階的に置き換え（各段階の終わりでサイトが動く）、認証と DB は Firebase Spark、解析は GA4 を続ける。2026-10-09 に確かめた無料枠の一次情報が理由で、Supabase Free は 7 日無操作で停止して手動復元が要り、Vercel Web Analytics はカスタムイベントが Pro 限定、GA4 の Cookie なし運用は月 50 人規模ではレポートに数字が出ない。
