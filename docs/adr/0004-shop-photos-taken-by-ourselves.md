# ADR 0004: 店の写真は自分で撮ったどんぶり写真だけを載せる

- 日付: 2026-10-06
- 状態: 採択

全店に無料で揃う画像として Google ストリートビューの外観を試したが（PR #62）、道路からの引きの画では店を同定できない店が多く見送った。店の写真は、自分で食べに行って撮ったどんぶり写真だけを、撮れた店から順に載せる。写真がない店には何も出さず、自動取得の仕組みは持たない。

## 検討した代替案

| 案 | 見送った理由 |
|---|---|
| Google ストリートビュー Static API の外観 | 無料枠内で全店に揃うが、店が写らない・引きすぎで品質が足りない（PR #62 で 28 店を目視） |
| Google Places Photos | 無料枠は月 1,000 回で、画像の保存・加工に制限があり規約がグレー |
| Wikimedia Commons・Flickr の CC 画像 | 収録している店の写真がほぼない（Commons の家系の写真は東京の 1 店に集中） |
| 店の公式 SNS の埋め込み | 投稿の削除で壊れ、外部スクリプトに依存する。作った後の手間が増える |
